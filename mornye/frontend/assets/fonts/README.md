# Bundled fonts

Variable WOFF2 files (Latin subset), loaded by `@font-face` at the top of
`mornye/frontend/styles.css`. Bundled so the desktop window works offline and
the web UI makes no third-party font requests.

| File | Family | Source | License |
|---|---|---|---|
| `Inter-Variable.woff2` | Inter (interface text) | `@fontsource-variable/inter@5.1.1` | SIL Open Font License 1.1 |
| `Fraunces-Variable.woff2` | Fraunces (display titles) | `@fontsource-variable/fraunces@5.1.1` | SIL Open Font License 1.1 |
| `JetBrainsMono-Variable.woff2` | JetBrains Mono (data) | `@fontsource-variable/jetbrains-mono@5.1.1` | SIL Open Font License 1.1 |

    Audio Quality
    Quality per serviceEach extension's own quality choices. "Use global quality" maps the tier above onto the closest one the extension offers
    Auto quality fallbackOn: accept a lower quality from the same provider when the requested quality is unavailable. Off: discard the lower-quality file and try the next provider at the same quality; the track fails only if no provider has it. With Dolby Atmos, only providers that offer Atmos (e.g. Tidal, Amazon) are tried, plus any service you set a quality for below (e.g. Amazon → Dolby Digital Plus).
    Verify Hi-Res authenticityFlags files that declare 96 kHz but whose content stops at CD range (upsampled), and 24-bit files that are really a padded 16-bit master. Adds a few seconds of analysis per track
    Replace fake Hi-ResOff = a finding is only reported. On = the flagged file is set aside, the track is re-downloaded as LOSSLESS, and the flagged file is deleted only once the replacement is on disk

    Self-hosted Endpoints

    Download through your own server. It is tried first; if it fails the extension falls back to its default API. Tidal expects a hifi-api compatible server, Qobuz a qobuz-rest-api compatible one, Amazon an amazon-music compatible one. A server on this machine or your LAN (http://192.168.1.10:8000) is allowed for that address only.

    Audio engine
    EngineNative plays the files itself through libmpv: bitstream, device choice, exclusive mode, gapless, ReplayGain and the equalizer. The window's own engine always decodes to PCM for the system mixer.
    Output
    Output device
    Exclusive modeTakes the device for itself (WASAPI exclusive, Core Audio hog mode): bit-perfect, and no other app is heard meanwhile.
    Bitstream (passthrough)Sends these formats compressed, for the receiver to decode. S/PDIF (coaxial, optical) carries AC-3 and DTS only; E-AC-3, DTS-HD and TrueHD need HDMI.
    Output channelsAuto follows the device. A smaller layout downmixes (normalized, without clipping).
    Upmix stereoSpreads stereo over 5.1 or 7.1 when that layout is chosen above.
    Playback
    GaplessThe next track is opened in advance and follows without a pause.
    ReplayGainFrom the files' tags; files without them play unchanged.
    ReplayGain pre-ampdB added on top of the tag's gain.
    0 dB
    Prevent clippingLowers the ReplayGain boost when it would clip.
    Audio delayMilliseconds; for a receiver or speakers that lag behind.
    0 ms
    Keep pitch when changing speedSpeed: [ and ] while playing, Backspace resets.
    NormalizationEvens out loud and quiet passages. Off for listening as mastered.
    Turn quiet songs upReplayGain then raises songs mastered quietly too, not only lowers loud ones; a limiter holds back their loudest moments. Needs ReplayGain on.

    Extension Settings

    Each extension's own options, as its manifest declares them — country, API URLs, tokens and so on. Secret values are never shown again once saved; leave the field empty to keep the current one.

    Extension Health

    How each provider has actually behaved on this machine — attempts, how often they worked, how long they took, and what the last failure said. Worst first. An extension listed as never tried is not broken; nothing has reached it yet, usually because another provider earlier in your service order keeps succeeding first.

    Signed Sessions

    The verified sessions extensions use to talk to their gateway, and when each one expires. An expired session is renewed with a new verification the next time it is needed. Orphaned ones were left behind by an extension update and are never used again.

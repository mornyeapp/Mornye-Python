Download through your own server. It is tried first; if it fails the extension falls back to its default API. Tidal expects a hifi-api compatible server, Qobuz a qobuz-rest-api compatible one. A server on this machine or your LAN (http://192.168.1.10:8000) is allowed for that address only.

Extension Settings

Each extension's own options, as its manifest declares them — country, API URLs, tokens and so on. A saved value reaches the extension the next time it starts, which is the next download, search or link lookup. Secret values are never shown again once saved; leave the field empty to keep the current one.

Extension Health

How each provider has actually behaved on this machine — attempts, how often they worked, how long they took, and what the last failure said. Worst first. An extension listed as never tried is not broken; nothing has reached it yet, usually because another provider earlier in your service order keeps succeeding first.

The verified sessions extensions use to talk to their gateway, and when each one expires. An expired session is renewed with a new verification the next time it is needed. Orphaned ones were left behind by an extension update and are never used again.
